# 🎯 الرؤية | Vision

> **عُدّة (Udda)** — مجموعة أدوات عربية مجانية ثنائية اللغة على الويب، مصممة للمستخدم العربي بلغة أصيلة وخصوصية تامة.

---

## 1. ما هي عُدّة؟

موقع ويب ثابت (static) يضم حاسبات ومحوّلات وأدوات نصية وغيرها — كل أداة تعمل في المتصفح مباشرة، بلا تسجيل، بلا تتبّع، بلا تطبيق. الاسم **"عُدّة"** يعني الأدوات التي يحتاجها كل عربي في يومه.

النطاق: [https://udda.tools](https://udda.tools)

## 2. المشكلة التي نحلها

المستخدم العربي اليوم يواجه:

| المشكلة | المثال |
|---|---|
| أغلب الأدوات الإنجليزية فقط | حاسبات GPA على المواقع الأجنبية مصممة للأنظمة الأمريكية فقط |
| الأدوات الإسلامية نادرة أو معقدة أو غير دقيقة | مواقع الزكاة كثيرة لكن قليل منها يدعم الذهب/الفضة/الأسهم بدقة فقهية |
| تتطلب تسجيلاً أو دفعاً أو تثبيت تطبيق | حاسبات الميراث المتقدمة غالباً مدفوعة أو مغلقة |
| لا تراعي السياق العربي/الإسلامي | حاسبات "interest" دون أي إشارة لموقف الشريعة من الربا |
| الترجمة الحرفية تفسد المعنى | "loan calculator" ≠ "حاسبة قرض" حين يكون السياق ربوياً |
| إعلانات تطفلية وتتبع غير أخلاقي | popups, autoplay video, third-party trackers |

## 3. الجمهور المستهدف

- **المستخدم العربي العام** — ليس تقنياً بالضرورة، يبحث عن جواب سريع لسؤال يومي
- **طلاب الجامعات والثانوي** — GPA, percentage, age calculators
- **الموظفون وأصحاب الدخل** — loan, interest, percentage, body health
- **المسلمون الباحثون عن أدوات شرعية** — zakat, inheritance, kaffara
- **المهتمون بالذكاء الاصطناعي** — ai-readiness assessment

## 4. لماذا عُدّة؟ (التميّز)

- **عربية أصيلة:** ليست ترجمة. الأدوات الإسلامية مكتوبة بمصطلحاتها الفقهية الصحيحة (نصاب، حول، عَول، رَدّ، حَجب)
- **ثنائية اللغة كاملة:** RTL/LTR، كل أداة بلغتين، روابط `hreflang` صحيحة
- **خصوصية تامة:** كل شيء client-side. لا نخزّن، لا نرسل، لا نتتبع
- **مجانية تماماً:** دخل الموقع من إعلانات AdSense غير مزعجة فقط
- **أدوات إسلامية مدققة:** زكاة وميراث وكفارات بمراجع فقهية + إخلاء مسؤولية واضح ("ليست فتوى")
- **بلا تسجيل:** افتح الموقع → استخدم الأداة → اخرج
- **سريعة:** صفحات HTML ثابتة، تحميل سريع، لا framework loading
- **قابلة للعمل offline (مستقبلاً عبر PWA)** — بعد التحميل الأول

## 5. ما لسنا

- لسنا منصة SaaS أو خدمة سحابية
- لسنا تطبيق موبايل native (Web App يعمل على كل الأجهزة)
- لسنا مرجع فتاوى — الأدوات الإسلامية حاسبات، لا فتاوى
- لا نجمع بياناتك ولا نبيع شيئاً
- لا نطلب اشتراكات أو حسابات أو إيميلات

## 6. القيم العليا

| القيمة | الوصف |
|---|---|
| الدقة قبل الجمال | حاسبة ميراث صحيحة فقهياً > حاسبة جميلة لكن خاطئة |
| البساطة قبل القوة | أداة سهلة لـ 90% من المستخدمين > أداة معقدة لـ 10% |
| الخصوصية قبل التحليلات | لن نضيف tracking لمعرفة سلوك المستخدم |
| العربية الأصيلة قبل الترجمة | كل نص بالعربية يُكتب بفهم السياق، لا يُترجم آلياً |
| التوثيق قبل الكود | ما لم نوثّقه لا نبنيه |

## 7. مقاييس النجاح (مقترحة للنقاش)

- **زيارات شهرية متزايدة** عبر السنوات
- **وقت الجلسة** — يدل على أن الأدوات تخدم احتياجاً فعلياً
- **نسبة المستخدمين العائدين** — الثقة المتراكمة
- **ترتيب SEO** للكلمات المفتاحية المستهدفة (خصوصاً العربية)
- **مشاركات اجتماعية للأدوات** — دليل على القيمة المُدركة
- **عدد التصنيفات المغطاة** — 8 تصنيفات معرّفة، 3 منها فعّالة حالياً
