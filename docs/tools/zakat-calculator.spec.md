# 🕌 حاسبة الزكاة | Zakat Calculator Spec

> أداة لحساب الزكاة الشاملة (نقد، ذهب، فضة، عروض تجارة، أسهم) + زكاة الفطر.
>
> **ID:** `zakat-calculator` · **التصنيف:** `calculators` · **الأيقونة:** 🕌

---

## 1. نظرة عامة

### الجمهور
- المسلم الذي يريد حساب زكاة أمواله السنوية بدقة
- الأسر التي تريد إخراج زكاة الفطر
- الباحثون عن أداة تدعم تنوع الأموال (ذهب بأعيرة، أسهم، عقارات استثمارية)

### المشكلة التي تحلها
كثير من حاسبات الزكاة على الإنترنت:
- تتعامل مع المال النقدي فقط (تتجاهل الذهب/الأسهم)
- لا تخصم الديون
- لا تشرح اختلاف العلماء (مثل أسهم المضاربة vs الاستثمار)
- لا تستخدم نصاب الفضة (الأحوط)
- لا توفّر نسخة عربية أصيلة بالمصطلحات الفقهية

### النتيجة
- مبلغ الزكاة الإجمالي بنسبة 2.5%
- المتبقي بعد الزكاة
- تقرير: هل بلغت النصاب؟ ما قيمته؟
- لزكاة الفطر: التكلفة الإجمالية حسب عدد الأسرة

## 2. المنطق والمعادلات

### 2.1 الزكاة الشاملة

**الصيغة الأساسية:**
```
صافي الأصول = (نقد + ذهب + فضة + عروض تجارة + أسهم) − الديون المستحقة
الزكاة = صافي الأصول × 2.5%
```
**شروطها:**
- صافي الأصول ≥ النصاب
- مرّ حول هجري كامل على بلوغ النصاب

### 2.2 النصاب

| المعيار | القيمة |
|---|---|
| نصاب الذهب | 85 جراماً (عيار 24) |
| نصاب الفضة | 595 جراماً (عيار 999) |

**القاعدة المطبقة:** يُحسب النصاب **بقيمة الفضة** (الأحوط) — لأنه أقل وبالتالي يشمل عدداً أكبر من المسلمين. هذا رأي جمهور الفقهاء المعاصرين.

```
نصاب_الفضة_بالنقد = 595 × سعر_جرام_الفضة_999
نصاب_الذهب_بالنقد = 85 × سعر_جرام_الذهب_24
نصاب_فعلي = min(نصاب_الفضة, نصاب_الذهب)
```

### 2.3 حساب الذهب بأعيرة مختلفة

```
وزن_الذهب_24 = الوزن × (العيار / 24)
قيمة_الذهب = وزن_الذهب_24 × سعر_جرام_24
```

| العيار | معامل التحويل |
|---|---|
| 24 | 1.000 |
| 22 | 0.917 |
| 21 | 0.875 |
| 18 | 0.750 |
| 14 | 0.583 |
| 10 | 0.417 |

### 2.4 الأسهم — التمييز الفقهي

**أسهم المضاربة (تداول):**
- تُزكّى على **كامل القيمة السوقية** بنسبة 2.5%
- لأن نية البيع موجودة (كعروض التجارة)

**أسهم الاستثمار (طويلة الأمد):**
- خلاف فقهي:
  - **رأي 1:** تُزكّى على **الأرباح الموزعة فقط**
  - **رأي 2:** تُزكّى على **القيمة السوقية كاملة**
- الأداة تعرض الخيارين، يختار المستخدم الرأي الذي يتبعه

### 2.5 الديون

تُخصم **الديون الحالّة فقط** (المستحقة الآن، أقساط هذا الشهر، فواتير قائمة).
**لا تُخصم** الديون طويلة الأجل كاملة (مثل قسط البيت 20 سنة).

```
صافي = إجمالي_الأصول − الديون_الحالّة
```

### 2.6 زكاة الفطر

**القاعدة:** صاع واحد من غالب قوت أهل البلد لكل فرد، ≈ 3 كغ.

```
الإجمالي = عدد_أفراد_الأسرة × مقدار_الصاع_بالكغ × سعر_الكيلو
```

يجوز إخراجها نقداً عند بعض العلماء (رأي الحنفية).

## 3. المراجع والمصادر

### القرآن
- نسبة الزكاة 2.5% من السنة النبوية (ربع العشر)
- وجوب الزكاة في القرآن في عشرات الآيات

### السنة
- "ليس فيما دون خمس أواقٍ صدقة" (نصاب الفضة، 5 أواق = 595g)
- "لا تجب فيها الزكاة حتى يحول عليها الحول"

### معايير عصرية
- **AAOIFI** (هيئة المحاسبة والمراجعة للمؤسسات المالية الإسلامية) — معيار الزكاة رقم 35
- **مجمع الفقه الإسلامي الدولي** — قرارات بشأن زكاة الأسهم والعقارات

### اختلاف المذاهب
- اختلافات بسيطة في النصاب وما يُخصم — الأداة تتبنى الرأي **الأحوط** للجمهور

## 4. الحالات الحافّة

| الحالة | السلوك |
|---|---|
| أصول < النصاب | لا تجب الزكاة، تظهر رسالة "لم تبلغ النصاب" |
| لا سعر ذهب مدخل | تظهر رسالة "أدخل سعر الذهب لحساب الزكاة" |
| ديون > أصول | صافي سالب → لا زكاة |
| سعر الفضة غير مدخل | يُحسب النصاب على أساس الذهب فقط (تنبيه) |
| أسهم استثمار = 0 + أرباح > 0 | تُزكّى الأرباح فقط |
| المسكن الشخصي والسيارة والأثاث | **لا تُحسب** (حسب الإجماع) |

```

```

- **تبويبان:** الزكاة الشاملة + زكاة الفطر
- **أقسام في "الشاملة":** نقد، ذهب، فضة، عروض تجارة، أسهم، ديون
