## 1. نظرة عامة

### الجمهور
- من يريد فهم تأثير الفائدة على استثماراته أو ديونه (تعليمياً)
- مقارنة بدائل التمويل الإسلامي (مع الفائدة التقليدية)

⚠️ **تنبيه شرعي إلزامي:** الفائدة الربوية محرّمة في الشريعة بإجماع العلماء. الأداة **تعليمية** — للفهم والمقارنة، لا للتشجيع.

## 2. المعادلات

### 2.1 الفائدة البسيطة

```
الفائدة = الأصل × المعدل × المدة
المبلغ_النهائي = الأصل + الفائدة
            = الأصل × (1 + المعدل × المدة)
```

### 2.2 الفائدة المركبة

```
المبلغ_النهائي = الأصل × (1 + المعدل/n)^(n × المدة)
```

حيث **n** عدد مرات التركيب في السنة:

| التركيب | n |
|---|---|
| سنوي | 1 |
| نصف سنوي | 2 |
| ربع سنوي | 4 |
| شهري | 12 |
| يومي | 365 |

### 2.3 جدول التراكم

تعرض الأداة جدولاً سنوياً:
- رصيد البداية
- الفائدة السنوية
- الفائدة المتراكمة
- الرصيد النهائي

## 3. الإخلاء الإلزامي

من i18n.json (`tools.interest-calculator.{lang}.disclaimer1-4`):

```
1. هذه الأداة حاسبة رياضية فقط، تقوم بحساب معادلات الفائدة البسيطة والمركبة
2. الفائدة الربوية (الربا) محرّمة في الشريعة الإسلامية بإجماع العلماء
3. الموقع لا يشجّع على التعامل بالربا ولا يتحمل مسؤولية استخدام هذه الأداة
4. قد تكون هذه الأداة مفيدة لأغراض تعليمية أو لحساب مستحقات قائمة أو لمقارنة البدائل الإسلامية
```
