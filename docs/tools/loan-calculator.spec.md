## 1. نظرة عامة

### الجمهور
- من لديه قرض أو يفكّر في الحصول على واحد
- مقارنة طرق احتساب الأقساط

⚠️ **تنبيه شرعي إلزامي:** القروض الربوية محرّمة في الشريعة. الأداة تعليمية للمقارنة بين الطرق ومقابلتها بالبدائل الإسلامية.

## 2. الأنواع الثلاثة

### 2.1 جدول الاستهلاك المتساوي (Amortized)

القسط الشهري ثابت، نسبة الفائدة من القسط تنقص تدريجياً والأصل يزيد.

```
القسط_الشهري = (الأصل × r × (1+r)^n) / ((1+r)^n − 1)
```
حيث:
- `r` = معدل الفائدة الشهري (سنوي/12)
- `n` = عدد الأشهر الكلي

### 2.2 الاستهلاك المتناقص (Declining)

**القسط أصلاً متساوٍ، الفائدة تنقص:**
```
القسط_الشهري = (الأصل / n) + (الرصيد_المتبقي × r)
```

**النتيجة:** القسط الأول الأعلى، القسط الأخير الأدنى.

### 2.3 الفائدة فقط (Interest Only)

دفع الفائدة فقط شهرياً، الأصل دفعة واحدة في النهاية.
```
القسط_الشهري = الأصل × r
الدفعة_الأخيرة = الأصل + r×الأصل
```

## 3. جدول الاستهلاك (Amortization Table)

تعرض الأداة جدولاً شهرياً:
- رقم القسط
- المبلغ المدفوع
- الجزء من الأصل
- الجزء من الفائدة
- الرصيد المتبقي
