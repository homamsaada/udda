# 🧮 أبو نجيب | Abu Najeeb — Trip Settlement Calculator Spec

> أداة لتسوية مصاريف الرحلات الجماعية بنموذج **أمين الصندوق**: كل شخص يتعامل مع شخص واحد فقط، فلا فوضى تحويلات في المجموعات الكبيرة.
>
> **ID:** `abu-najeeb` · **التصنيف:** `everyday` · **الأيقونة:** 🧮

---

## 1. نظرة عامة

### الجمهور
- مجموعات الرحلات (10+ أشخاص شائع، لكن من 2 إلى 50)
- عائلات في إجازات مع مرافقين (أطفال، ضيوف)
- شركاء سكن للمصاريف المشتركة

### المشكلة
- بعد رحلة جماعية، عدّة أشخاص دفعوا لأشياء مختلفة من مال خاص
- "كل شخص يطلع نصيبه" يُنتج فوضى تحويلات (N×M)
- خوارزميات Greedy تُقلّل العدد، لكن **كل شخص قد يتعامل مع عدّة أشخاص** = مرهق نفسياً
- **نموذج "أمين الصندوق"** (أمير الرحلة): شخص واحد يجمع من الجميع ويُسلّم للجميع → كل فرد له معاملة واحدة فقط

### النتيجة
- **عرض افتراضي:** أمين الصندوق + قائمتان (يجمع من / يُسلّم لـ)
- **عرض بديل:** Greedy (الأقل تحويلاً)
- المستخدم يبدّل بين العرضَين بزر واحد

---

## 2. الفلسفة المعمارية (تطوُّر من الإصدار الأول)

الإصدار الأول كان به 4 تبويبات (متساوي/استهلاك/تسوية/نسب). **خلطت** بين:
- طُرق التقسيم (متساوي/استهلاك/نسب) — هذه خيارات إدخال
- التسوية (من دفع لمن) — هذا المخرج النهائي

الإصدار الحالي **trip-only موحَّد**:
- المُدخَل: أشخاص + مصاريف (مع `paidBy` و `sharedWith`)
- المخرَج: تسوية (Treasurer أو Greedy)
- "التقسيم" متضمَّن في `sharedWith` (شخص واحد = استهلاكه، الجميع = متساوي، subset = مجموعة)

---

## 3. التدفّق

```
1. إضافة أشخاص (الحدّ 2-50، مع مرافقين اختياريين)
2. عملة اختيارية (نصّ يُلصق بالنتيجة)
3. إضافة مصاريف:
   - وصف + مبلغ + من دفع + لمن (الجميع / شخص / مجموعة)
4. الأداة تحسب:
   - net[p] = Σ(دفع p) − Σ(نصيب p من كل مصروف)
5. اختيار أمين الصندوق (تلقائي = أكبر دائن، يدوي = dropdown)
6. عرض النتيجة:
   - Treasurer (افتراضي): يجمع من المدينين، يُسلّم للدائنين
   - Greedy (toggle): قائمة تحويلات peer-to-peer
```

## 4. نموذج أمين الصندوق — تفصيل

### الفكرة
**كل شخص يتعامل مع شخص واحد (الأمين) فقط:**
- المدينون: يُسلّمون الأمين فروقاتهم
- الدائنون: يأخذون من الأمين فروقاتهم
- الأمين: يجمع كل العجز ويُسلّم كل الفائض (يتوازن في النهاية)

### اختيار الأمين

**تلقائي (افتراضي):**
- أكبر دائن (الشخص الذي دفع أكثر مقارنة بنصيبه)
- الفكرة: غالباً هو الذي تكفّل بالنفقات الكبيرة، فمن المنطقي أن يُكمل دور التجميع

**يدوي:**
- المستخدم يُغيِّر من dropdown
- مفيد لو شخص آخر متطوّع لإدارة الصندوق (مدير الرحلة، الأكبر سناً، إلخ)

### الإخراج
```
⭐ أمين الصندوق: أحمد (مقترح تلقائياً — أكبر دائن)

💰 يُسلَّم له (يجمع من المدينين):
  - خالد: 200
  - سارة: 150
  - عمر: 100

💸 يُسلِّم منه (يدفع للدائنين):
  - لينا: 300
  - فاطمة: 150
```

### مقارنة بـ Greedy

| المعيار | Treasurer | Greedy |
|---|---|---|
| عدد المعاملات الكلية | (debtors + creditors − 1) | ≤ max(debtors, creditors) |
| معاملات لكل شخص | 1 فقط | 1-N (متفاوت) |
| سهولة الإدارة | عالية (شخص واحد ينسّق) | متوسطة (كل شخص يتذكّر) |
| الملاءمة | مجموعات >5 | مجموعات صغيرة |

**القرار:** Treasurer هو الافتراضي. Greedy متاح كـtoggle لمن يفضّله.

## 5. المرافقون (Companions)

كل شخص له:
- `companions`: عدد المرافقين (افتراضي 0)
- `companionShare`: نوع نصيب كل مرافق

**3 presets:**
| النصيب | المضاعف |
|---|---|
| كامل (`full`) | 1.0 |
| نصف (`half`) | 0.5 |
| ربع (`quarter`) | 0.25 |

**المعادلة:** `weight(p) = 1 + companions × multiplier`

**خارج النطاق (v2):** نسب مخصّصة (custom %).

## 6. القواعد العامة

| القاعدة | التفاصيل |
|---|---|
| الأرقام | صحيحة فقط، `Math.round` بعد كل قسمة |
| العملة | حقل اختياري نصّي، يُلصق بالنتيجة، لا يدخل الحساب |
| التنسيق الموقعي | **الأرقام بالإنكليزية في AR + EN** (قرار 2026-05-11) |
| الحدّ الأدنى | 2 أشخاص + مصروف واحد |
| الحدّ الأقصى | 50 شخصاً |
| التوازن | rounding diff يُمتَصّ في آخر share/transfer |
| الأمين الافتراضي | أكبر دائن (تلقائي) |

## 7. الميزات

### 7.1 جرّب مثالاً (`seedDemo`)
رحلة عملية: 5 أشخاص، 4 مصاريف (بنزين/فندق/عشاء/متحف). سارة معها طفل-نصف.

### 7.2 نسخ النتيجة (`copyResult`)
نصّ منسَّق لكل وضع (treasurer أو greedy):
```
💰 أبو نجيب — تسوية الرحلة
مجموع المصاريف: 2,130 ر.س
عدد الأشخاص: 5

⭐ أمين الصندوق: أحمد

💰 يُسلَّم لأحمد:
- خالد: 350
- سارة: 200

💸 أحمد يُسلِّم:
- عمر: 150
```

### 7.3 sessionStorage + Saved Groups
- `udda:abu-najeeb:session` — auto-save الحالة الكاملة
- `udda:abu-najeeb:groups` — مجموعات أشخاص محفوظة بالاسم

### 7.4 تصدير صورة (html2canvas vendor lazy)
- ~195KB، يُحمَّل عند الطلب فقط
- يلتقط `.calc-result` كاملة (مع stats + treasurer view + transfers)

## 8. الحالات الحافّة

| الحالة | السلوك |
|---|---|
| أقل من شخصين | رسالة "أضف شخصين على الأقل" |
| لا مصاريف | لا نتيجة (إخفاء `.calc-result`) |
| مبلغ ≤ 0 | رفض + رسالة |
| الكل متعادل | "✅ الجميع متعادل، لا توجد ديون 🎉" |
| الأمين = الوحيد الدائن وكل الباقين مدينون | Treasurer يعمل بصورة طبيعية، disburses فارغ |
| حذف شخص = paidBy لمصروف | منع الحذف + رسالة "غيِّر الدافع أولاً" |
| حذف شخص ≠ paidBy | حذف cascade من sharedWith |
| Σ rounding errors ≠ 0 | امتصاص في آخر transfer/disburse |
| تغيير الأمين | إعادة حساب فورية |

## 9. الملاحظات المعمارية

### الملف
```
src/tools/abu-najeeb.html (~1,100 سطر)
```

### Wrapper class
`.abu-najeeb`

### Prefix للأنماط الخاصة
`an-*`

### استهلاك Standard Calc Kit
```
.calc-form, .calc-form-row, .calc-form-group  ← حقول الإدخال
.calc-stats-grid, .calc-stat-card             ← stats بانر
.calc-result.show                             ← حاوية النتيجة
```

⚠️ **لا تبويبات في هذا الإصدار** — `.calc-tabs/.calc-tab/.calc-pane` غير مُستخدمة.

### State (مركزي)
```js
state = {
  currency: '',
  editingPersonId: null,
  editBuffer: null,
  people: [],
  expenses: [],
  treasurer: personId | null,        // null = auto = أكبر دائن
  settlementMode: 'treasurer' | 'greedy'
};
```

### Persistence
- `sessionStorage["udda:abu-najeeb:session"]`
- `localStorage["udda:abu-najeeb:groups"]`

### Reactivity
كل تعديل state يستدعي `renderAll()` → `renderPeopleList + renderExpenses + renderResult + saveSession`.
