# 🎂 حاسبة العمر | Age Calculator Spec

>
> **ID:** `age-calculator` · **التصنيف:** `calculators` (subcategory: `other`) · **الأيقونة:** 🎂

---

## 1. نظرة عامة

### الجمهور
- من يريد معرفة عمره بدقة لحظية
- من يحسب الفترة بين تاريخين (مدة العمل، مدة الزواج، إلخ)
- من يحتاج إضافة/طرح أيام من تاريخ

### الـ3 تبويبات
1. **حساب العمر** — تاريخ الميلاد → العمر الحالي
2. **الفرق بين تاريخين** — تاريخان → الفترة بينهما
3. **جمع/طرح من تاريخ** — تاريخ + N (يوم/شهر/سنة) → تاريخ جديد

## 2. المعادلات

### العمر الدقيق
```js
const now = new Date();
const birth = new Date(birthDate);
const diffMs = now - birth;

const years  = Math.floor(diffMs / (365.25 * 86400000));
const months = ...   // باستخدام التواريخ الفعلية لتجنب الانحراف
const days   = ...
const hours  = Math.floor(diffMs / 3600000) % 24;
```

### Live mode
زر "تحديث مباشر" — العمر يتحدّث كل ثانية (يحسب الثواني الحقيقية).

## 3. الحالات الحافّة

| الحالة | السلوك |
|---|---|
| تاريخ المستقبل | "تاريخ غير صالح" أو "بعد X يوم" |
| 29 فبراير في سنة غير كبيسة | يستخدم 28 فبراير أو 1 مارس |
| الفرق بين شهور تختلف بأطوالها | حساب يوم بيوم لتجنب التقريب |
