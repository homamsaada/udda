## 2. الحسابات الـ5

### 2.1 BMI — مؤشر كتلة الجسم

```
BMI = الوزن(كغ) / الطول(م)²
```

**التصنيف (WHO):**
| المدى | التصنيف |
|---|---|
| < 18.5 | نقص وزن (Underweight) |
| 18.5 – 24.9 | طبيعي (Normal) |
| 25.0 – 29.9 | زيادة وزن (Overweight) |
| 30.0 – 34.9 | سمنة من الدرجة 1 |
| 35.0 – 39.9 | سمنة من الدرجة 2 |
| ≥ 40.0 | سمنة مفرطة (Severe / Class 3) |

**المرجع:** WHO Global Database on BMI

### 2.2 BMR — معدّل الأيض الأساسي

استخدام **معادلة Mifflin-St Jeor** (الأدق عند الجمهور):

**للذكر:**
```
BMR = (10 × الوزن) + (6.25 × الطول_سم) − (5 × العمر) + 5
```

**للأنثى:**
```
BMR = (10 × الوزن) + (6.25 × الطول_سم) − (5 × العمر) − 161
```

**حساب السعرات اليومية (TDEE):**
```
TDEE = BMR × معامل_النشاط
```

| النشاط | المعامل |
|---|---|
| كسول | 1.2 |
| نشاط خفيف | 1.375 |
| نشاط متوسط | 1.55 |
| نشاط عالٍ | 1.725 |
| نشاط شديد | 1.9 |

**المرجع:** Mifflin et al., *Am J Clin Nutr*, 1990

### 2.3 IBW — الوزن المثالي

**معادلة Devine** (الأشهر):

**للذكر:**
```
IBW = 50 + 2.3 × ((الطول_سم − 152.4) / 2.54)
```

**للأنثى:**
```
IBW = 45.5 + 2.3 × ((الطول_سم − 152.4) / 2.54)
```

**ملاحظة:** هذه معادلة تقديرية. الوزن "المثالي" يختلف حسب البنية والعرق والعمر.

**المرجع:** Devine BJ., *Drug Intell Clin Pharm*, 1974

### 2.4 Body Fat — نسبة الدهون

استخدام **معادلة Deurenberg** (BMI-based):

**للذكر:**
```
BF% = (1.20 × BMI) + (0.23 × العمر) − 16.2
```

**للأنثى:**
```
BF% = (1.20 × BMI) + (0.23 × العمر) − 5.4
```

**التصنيف (للذكر):**
| المدى | التصنيف |
|---|---|
| 2-5% | رياضي محترف |
| 6-13% | رياضي |
| 14-17% | لياقة جيدة |
| 18-24% | عادي |
| ≥ 25% | سمين |

**التصنيف (للأنثى):**
| المدى | التصنيف |
|---|---|
| 10-13% | رياضية محترفة |
| 14-20% | رياضية |
| 21-24% | لياقة جيدة |
| 25-31% | عادي |
| ≥ 32% | سمينة |

**المرجع:** Deurenberg P, *Br J Nutr*, 1991

### 2.5 WHR — نسبة الخصر إلى الورك

```
WHR = محيط_الخصر / محيط_الورك
```

**التصنيف (WHO):**
| الجنس | منخفض | متوسط | عالٍ |
|---|---|---|---|
| ذكر | < 0.90 | 0.90 – 0.99 | ≥ 1.0 |
| أنثى | < 0.80 | 0.80 – 0.84 | ≥ 0.85 |

**الأهمية:** WHR أفضل من BMI في تقييم خطر أمراض القلب والسكري (دهون البطن المركزية).

**المرجع:** WHO Expert Consultation, 2008

## 3. الحالات الحافّة

| الحالة | السلوك |
|---|---|
| الطفل (< 18 سنة) | تنبيه: المعادلات للبالغين، استخدم منحنيات نمو الأطفال |
| الحامل | تنبيه: BMI و IBW غير دقيقين |
| الرياضي المحترف | BMI قد يُظهر "زيادة وزن" بسبب العضلات (تنبيه) |
| كبار السن (> 65) | تنبيه: المعادلات قد تحتاج تعديلاً |
| الطول/الوزن خارج المدى الطبيعي | تنبيه أو رسالة خطأ |
| BMI < 10 أو > 80 | رسالة "أدخل قيماً واقعية" |
