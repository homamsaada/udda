# 🎓 حاسبة GPA | GPA Calculator Spec

> 20 نظام تقدير عالمي + 5 تبويبات (فصلي/تراكمي/متعدد/محوّل/مرجع) + 4 سياسات إعادة + تخصيص كامل.
>
> **ID:** `gpa-calculator` · **التصنيف:** `calculators` (subcategory: `other`) · **الأيقونة:** 🎓

---

## 1. نظرة عامة

### الجمهور
- طلاب الجامعات (سعودي، خليجي، عربي، عالمي)
- خريجون يحتاجون تحويل GPA للدراسة بالخارج
- مستشارون أكاديميون

### النتيجة
- GPA فصلي مع التقدير
- GPA تراكمي + تنبؤ ("ما GPA تحتاج لرفع تراكميك إلى X؟")
- GPA لعدة فصول مع رسم بياني للأداء
- تحويل بين 20 نظام تقدير
- جدول مرجعي لكل النظم

## 3. التبويبات الـ5

### 3.1 GPA الفصلي (Semester)

**الإدخال:** قائمة مواد، كل مادة:
- اسم
- الكريديتس
- التقدير (من dropdown أو نسبي)
- زر "إعادة" (لو إعادة، يدخل التقدير القديم)
- "ماذا لو" (تقدير افتراضي للمقارنة)

**الإخراج:**
- GPA الفصلي
- التصنيف (ممتاز/جيد جداً/...)
- مقارنة مع what-if إن وُجد

**المعادلة:**
```
GPA = Σ(value_i × credits_i) / Σ(credits_i)
```

### 3.2 الـ GPA التراكمي (Cumulative)

3 أقسام تتشارك inputs:
1. **حسابي:** GPA حالي + كريديتس مكتسبة + (نتائج الفصل الجديد) → التراكمي الجديد
2. **هدف:** "ما GPA تحتاج هذا الفصل لرفع التراكمي إلى X؟"
3. **حد أقصى:** "ما أعلى GPA تراكمي ممكن قبل التخرج؟"

**الـ inputs المشتركة:**
- GPA الحالي
- الكريديتس المكتسبة
- إجمالي كريديتس التخرج (للأقسام 2 و 3)

`getEffectiveEarned()` يحسب القيم مرة واحدة، تستخدمها كل الأقسام.

### 3.3 GPA لعدة فصول (Multi)

- إدخال GPA كل فصل + كريديتسه
- رسم بياني للأداء عبر الفصول
- إظهار أفضل/أسوأ فصل
- التراكمي النهائي

### 3.4 المحوّل (Converter)

تحويل بين أي نظامين عبر **النسبة المئوية كوسيط**:

```
toPercent(value, fromSystem) → percentage
fromPercent(percentage, toSystem) → value
```

استخدام **piecewise linear interpolation** على حدود التقديرات.

⚠️ **تحذير دائم:** التحويل تقريبي. لـ WES و IIE استشر المؤسسة المستقبلة.

### 3.5 المرجع (Reference)

جداول مرجعية لكل الـ20 نظام (التقديرات + التصنيفات + الحدود).

## 4. التخصيص (Customization)

المستخدم يستطيع:
- تعديل قيم التقديرات (مثلاً تغيير قيمة A+ من 5.00 إلى 4.95)
- إضافة/حذف تقديرات
- تغيير الـ max
- تصدير/استيراد JSON للحفظ

`customizations` object يُخزَّن في localStorage. عند تخصيص نظام، يظهر "/ مخصص" في dropdown.

`getActiveTemplate(templateId)` يُرجع النظام المعدّل أو الأصلي.

## 5. سياسات الإعادة (Retake Policies)

`retakePolicy` يأخذ 4 قيم:

| القيمة | السياسة |
|---|---|
| `replace` | الإعادة تستبدل القديم (الأكثر شيوعاً في السعودية) |
| `best` | الأعلى يُحسب |
| `countAll` | الإعادة والأصل كلاهما يُحسبان |
| `average` | متوسط الإعادة والأصل |

**التطبيق:**
- زر "إعادة" يفعّل حقل "التقدير القديم"
- `retakeAdj` يُحفظ التعديل (credits/points) ليُستخدم في `getEffectiveEarned()`

## 6. النظام المقلوب (German)

`isInverted(templateId)` يُرجع `true` للنظام الألماني (1.0 = أفضل، 5.0 = رسوب).

**التأثيرات:**
- `calcMaxGpa`: أفضل ممكن = 1.0 (ليس max)
- `calcTarget`: مستحيل لو الهدف < 1.0
- `calcMulti`: best/worst معكوسان، أعمدة الرسم معكوسة
- `calcCumulative`/`calcWhatIf`: ألوان مؤشر التغيير معكوسة
- `renderRefTables`: ترتيب التصنيفات معكوس

## 7. الحالات الحافّة

| الحالة | السلوك |
|---|---|
| لا مواد | GPA = — |
| كريديتس = 0 | المادة لا تُحسب |
| إعادة بدون تقدير قديم | يُحسب التقدير الجديد فقط |
| نظام نسبي (100, 20) | dropdown يُستبدل بـ input نسبي |
| GPA > max | تحذير "أدخل قيمة صحيحة" |

## 8. الملاحظات المعمارية

### الملف
```
src/tools/gpa-calculator.html (~3,580 سطر — ثاني أطول أداة)
```

### Wrapper class
`.gpa-calculator`

### Layout
- **بطاقة إعدادات 1:** dropdown النظام + زر "تخصيص" + الوصف
- **بطاقة إعدادات 2:** dropdown سياسة الإعادة + الوصف
- **شريط حفظ/تحميل:** داخل تبويب الفصلي
- **5 تبويبات:** الفصلي، التراكمي، عدة فصول، محوّل، مرجع

### بنية مادة (Course)
```js
{
  name, credits,
  gradeIndex, gradeValue,
  isRetake, oldGradeIndex, oldGradeValue,
  altGradeIndex, altGradeValue   // what-if
}
```

### Grid على Desktop
7 أعمدة: `1fr 70px 140px 50px 140px 140px 30px` (اسم، كريديتس، تقدير، إعادة، قديم، what-if، حذف).

### Layout على الموبايل
`display: flex; flex-wrap: wrap` — 4 أسطر للمادة الواحدة.

### الـ Helper المركزي
`getActiveTemplate(templateId)` — كل الحسابات و UI تستخدمه. **لا تقرأ `templates[currentTemplate]` مباشرة** (إلا لأخذ الاسم الأصلي في dropdown).

### الـ Save/Load
`gpaSaveData()` يصدّر JSON يحوي: template, customizations, retakePolicy, courses, semesters, cumulative inputs, converter state.
