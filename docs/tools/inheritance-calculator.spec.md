# ⚖️ حاسبة المواريث | Inheritance Calculator Spec

> الأداة الأكثر تعقيداً فقهياً وبرمجياً في الموقع — 4 مذاهب، حالات نادرة، طبقات ورثة ديناميكية.

## 1. نظرة عامة

### الجمهور
- ورثة يريدون معرفة نصيب كل وارث قبل التوزيع الرسمي
- محامون وموظفو محاكم شرعية (للتحقق السريع)
- طلاب الفقه والشريعة
- باحثون فقهيون يقارنون بين المذاهب

### المشكلة التي تحلها
- علم الفرائض (الميراث) من أعقد علوم الفقه
- حاسبات الميراث المتاحة:
  - تتبنى مذهباً واحداً عادة (غالباً السني الحنفي)
  - تتجاهل حالات الأَوْل والرَّدّ
  - لا تتعامل مع الطبقات الديناميكية (أبناء الأبناء، أجداد، إلخ)
  - عربية ضعيفة فقهياً

### النتيجة
- نصيب كل وارث (نسبة + مبلغ)
- شرح "لماذا" كل وارث استحق ما استحق (فرض/تعصيب/سبب الحَجب)
- إظهار الحالات الخاصة (أَوْل، رَدّ، مُشتركة، إلخ)

## 2. المنطق الفقهي

### 2.1 المذاهب الأربعة

الأداة تدعم:
- **حنفي**
- **مالكي**
- **شافعي**
- **حنبلي**

كل مذهب له اختلافات في:
- ما هي الفروض المقدّرة (1/2, 1/3, 1/4, 1/6, 1/8, 2/3)
- من يحجب من
- التعامل مع الرَّدّ (الشافعي **لا** يقبل الرَّدّ، الحنبلي يقبله للزوجين)
- حالات خاصة كالأكدرية والمشتركة

### 2.2 أصناف الورثة

**الفروض (أصحاب الفروض المقدّرة):**
- الزوج: 1/2 (لا فرع وارث) أو 1/4 (مع فرع)
- الزوجة: 1/4 (لا فرع) أو 1/8 (مع فرع)
- الأب: 1/6 (مع فرع وارث ذكر) — أو يجمع مع التعصيب
- الأم: 1/3 (لا فرع ولا جمع إخوة) أو 1/6 (مع فرع أو جمع إخوة)
- البنت/البنات: 1/2 (واحدة) أو 2/3 (جماعة)
- بنات الابن: 1/2 أو 2/3 أو 1/6 (تكملة الثلثين)
- الأخوات الشقيقات: 1/2 أو 2/3
- الأخوات لأب: 1/2 أو 2/3 أو 1/6
- الإخوة لأم: 1/6 (واحد) أو 1/3 (جماعة)
- الجدة: 1/6

**التعصيب (الباقي بعد الفروض):**
- الابن، ابن الابن، الأب (في غياب الفرع الذكر)
- الأخ الشقيق، الأخ لأب، أبناؤهم
- العمّ، ابن العمّ

**ذوو الأرحام (للجد والجدة من جهات بعيدة):**
- يرثون فقط في غياب أصحاب الفروض والتعصيب
- يُعالجهم `calculateArham()` في الكود

### 2.3 الحَجب (Hajb)

**حَجب الحرمان:** يُمنع الوارث كلياً.
**حَجب النقصان:** يُنقص نصيبه.

أمثلة:
- **الجدة محجوبة بالأم**
- **الأخوات لأب محجوبات بالأخ الشقيق**
- **بنات الابن محجوبات ببنتين أو أكثر** (إلا للتعصيب)

### 2.4 الأَوْل (Awl)

عندما يزيد مجموع الفروض على الواحد الصحيح، تُقسَّم الفروض **بالتناسب**:
```
نسبة_التناسب = 1 / مجموع_الفروض
نصيب_جديد = نصيب_فرض × نسبة_التناسب
```
**مثال شهير:** زوج + أختان شقيقتان → 1/2 + 2/3 = 7/6 > 1
بعد الأَوْل: الزوج 3/7، الأختان 4/7

### 2.5 الرَّدّ (Radd)

عندما تكون الفروض < 1 ولا يوجد عاصب، يُردّ الباقي على أصحاب الفروض **بنسبة فروضهم**.

**استثناءات:**
- **الزوج/الزوجة لا يُردّ عليهم** عند جمهور المذاهب
- **الحنبلي:** يُردّ على الزوج/الزوجة في غياب أي وارث آخر
- **الشافعي:** **لا يقبل الرَّدّ مطلقاً** — يذهب الفائض لبيت المال

### 2.6 حالات خاصة

#### المُشتركة (الحمارية)
- زوج + أم + إخوة لأم + إخوة أشقاء
- النصيب = للأشقاء صفر (لأن الإخوة لأم استنفذوا 1/3)
- **عند عمر بن الخطاب:** يُشركون في الثلث (الحنابلة والمالكية)
- **عند علي:** الأشقاء يأخذون صفر (الحنفية والشافعية)

#### الأكدرية
- زوج + أم + جد + أخت شقيقة
- مذهب زيد بن ثابت (المعتمد عند الجمهور): الجد يجمع نصيبه مع الأخت

#### العُمَريّتان (الغرّاوان)
- زوج + أبوان → الأم تأخذ ثلث الباقي بعد الزوج
- زوجة + أبوان → الأم تأخذ ثلث الباقي بعد الزوجة

#### المسألة المالكية (الجد مع الإخوة)
- الجد + الإخوة الأشقاء/لأب: المُقاسَمة (الحنابلة والمالكية)
- الجد يحجب الإخوة جميعاً (الحنفية)

## 3. المراجع والمصادر

### الكتب الأساسية
- **تبيين الحقائق** للزيلعي (الحنفي)
- **شرح الخرشي** على مختصر خليل (المالكي)
- **مغني المحتاج** للشربيني (الشافعي)
- **المغني** لابن قدامة (الحنبلي)
- **الفرائض في الفقه الإسلامي المقارن** — مرجع جامعي حديث

### القرآن
- **آيات الميراث** الرئيسية: النساء 11-12، 176

### السنة
- "ألحقوا الفرائض بأهلها فما بقي فلأولى رجل ذكر" (متفق عليه)
- "إنما الميراث لمن أدلى بنفسه" (تأسيس قاعدة الإدلاء)

## 4. الحالات الحافّة

| الحالة | السلوك |
|---|---|
| لا ورثة | تظهر رسالة "أدخل ورثة" |
| تركة = 0 | تُحسب النسب فقط (للتعليم) |
| كل الورثة محجوبون | يذهب للأرحام أو بيت المال (حسب المذهب) |
| ابن واحد فقط | يأخذ الكل (تعصيب) |
| 7 طبقات أحفاد | تُتاح حتى 7 طبقات ديناميكياً |
| الخنثى المشكِل | غير مدعومة حالياً (في ROADMAP) |
| المفقود/الأسير | غير مدعومة حالياً (في ROADMAP) |

## 5. الملاحظات المعمارية

### الملف الواحد
```
src/tools/inheritance-calculator.html (~2,861 سطر — الأطول والأعقد)
```

### الطبقات الديناميكية (`dynState`)

المستخدم يضيف طبقات أعمق من الورثة:
- `dynDescM{N}` — أبناء الأبناء (ذكور)
- `dynDescF{N}` — بنات الأبناء (إناث)
- `dynGf{N}` — أجداد عُلوية
- `dynGmP{N}` — جدات من جهة الأب
- `dynGmM{N}` — جدات من جهة الأم
- `dynExtFull{N}` — عصبة بعيدة (أشقاء)
- `dynExtPat{N}` — عصبة بعيدة (لأب)

**الحد الأقصى:** 7 طبقات لكل صنف. تُدار عبر `inhAddLayer(category)` و `createHeirRow()`.

### نظام الحَجب
```js
getBlockReason(heirId) → السبب أو null
updateHeirStates() → يلغي تلقائياً اختيار الورثة المحجوبين
```

قواعد الحَجب تتغير حسب المذهب المختار.

### `assignShares()` — قلب المحرّك

الدالة الجوهرية. تتعامل مع:
1. **الفروض المقدّرة** (1/2, 1/3, 1/4, 1/6, 1/8, 2/3)
2. **التعصيب** (الباقي بعد الفروض)
3. **الأَوْل** — التناسب عند تجاوز 1
4. **الرَّدّ** — توزيع الفائض حسب المذهب
5. **الحالات الخاصة** (المشتركة، الأكدرية، العُمَريّتان، الجد مع الإخوة)

### نمط Shared pool (الأقارب من جهة واحدة)

عندما يشترك ورثة في فرض واحد (مثلاً إخوة لأم في 1/3):
```js
entry.parts = sharedPoolParts * entry.count / entry.shared;
```

### ذوو الأرحام
دالة منفصلة `calculateArham(arhamHeirs, spouseHeirs, madhab, net)` تُستدعى **فقط** في غياب أصحاب الفروض/التعصيب.
