# 🌳 شجرة العائلة | Family Tree Spec

> أداة بناء شجرة عائلة تفاعلية بالـ SVG — لا حسابات فقهية أو طبية، أداة UI/تنظيم.
>
> **ID:** `family-tree` · **التصنيف:** `everyday` · **الأيقونة:** 🌳

---

## 1. نظرة عامة

### الجمهور
- العوائل التي تريد توثيق شجرتها للذكرى
- باحثون في الأنساب
- استخدام تعليمي للأطفال

### النمط
- إضافة أشخاص يدوياً (اسم، تاريخ ميلاد، صورة optional)
- إنشاء علاقات (أب/أم، زوج/زوجة، أبناء)
- الأداة ترسم الشجرة تلقائياً بـ SVG
- إمكانية الحفظ في localStorage + تصدير/استيراد JSON

## 2. النموذج (Data Model)

```js
{
  people: [
    {
      id: 'p1',
      name: 'محمد',
      gender: 'male',
      birthDate: '1980-01-15',
      photo: 'data:image/...',  // base64 أو URL
    }
  ],
  relationships: [
    { type: 'spouse',  a: 'p1', b: 'p2' },
    { type: 'parent',  parent: 'p1', child: 'p3' }
  ]
}
```

## 3. خوارزمية الرسم

### `calcTreeWidth(personId, visited)` (السطر 1758)
- يحسب عرض الشجرة الفرعية لكل شخص (DFS)
- يستخدم `visited Set` لتجنب الحلقات اللانهائية (في حالة الزواج بين الأقارب)
- النتيجة تستخدم في تخطيط الـ layout

### الـ Layout
- Top-down (الأجداد فوق، الأحفاد تحت)
- الأزواج جنباً إلى جنب
- الأبناء تحت الأبوين بخطوط رابطة
- التباعد العمودي والأفقي ثابت

## 4. التفاعل

- **نقر على شخص:** فتح modal للتعديل/الحذف
- **زر "إضافة":** نموذج إضافة شخص + تحديد العلاقة
- **سحب وإفلات:** غير مدعوم حالياً (في ROADMAP)
- **Zoom:** غير مدعوم حالياً

## 5. الحفظ والاستيراد

- **localStorage:** بمجرد التعديل (auto-save)
- **تصدير JSON:** زر يولّد ملف `.json` للتحميل
- **استيراد JSON:** زر يقرأ الملف ويُعيد بناء الشجرة

## 6. الملاحظات المعمارية

### الملف
```
src/tools/family-tree.html (~2,379 سطر)
```

### Wrapper class
`.family-tree`

### الـ SVG Rendering
- استخدام `<svg>` مباشرة (ليس Canvas)
- الـ children تحت `<g>` لتجميع كل شخص
- `<line>` للعلاقات
- خط الزواج أفقي، خط الأبوّة عمودي
