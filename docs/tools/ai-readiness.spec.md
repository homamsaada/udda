# 🤖 أداة تقييم الجاهزية للذكاء الاصطناعي | AI Readiness Assessment Spec

> الأداة الأكبر في الموقع — اختبار تفاعلي يقيس جاهزية المستخدم لعصر الذكاء الاصطناعي. 41 تخصصاً، ~200K سطر JSON بنك أسئلة.
>
> **ID:** `ai-readiness` · **التصنيف:** `generators` · **الأيقونة:** 🤖

---

## 1. الفكرة العامة

أداة تقييم ذاتي تفاعلية تقيس مدى جاهزية المستخدم لعصر الذكاء الاصطناعي.

### المميزات
- **مجانية بالكامل** بدون تسجيل أو حساب
- **فورية** — النتيجة تظهر مباشرة بعد الانتهاء
- **خفيفة** — عدد أسئلة يتكيّف مع المدة المختارة، من بنك أسئلة كبير
- **تقرير تفاعلي** متكامل مع رسوم بيانية وتوصيات مخصصة
- **Client-side بالكامل** — JS خالص، لا backend
- **الربح:** إعلانات AdSense

## 2. تدفق الاختبار

```
المرحلة 0 — بيانات أساسية
    ├── الاسم (اختياري)
    └── اختيار مدة الاختبار (5/10/15/20/30 دقيقة)

المرحلة 1 — أسئلة عامة
    └── أسئلة مشتركة لجميع المستخدمين (عدد حسب المدة)
        ├── معرفة أساسية بالذكاء الاصطناعي
        ├── ممارسة فعلية واستخدام أدوات
        └── مرونة واستعداد للتغيير

المرحلة 1.5 — اختيار التخصص
    └── شاشة وسيطة بعد العامة، قبل التخصصية
        ├── اختيار تخصص واحد أو أكثر من 41
        └── تُحمَّل ملفات الأسئلة التخصصية ديناميكياً

المرحلة 2 — أسئلة تخصصية (مع بعض العامة)
    └── 65% تخصصية + 35% عامة، مع أسئلة عامة متبقية مدمجة
        └── عدة تخصصات: توزيع متوازن

النتيجة — تقرير تفاعلي متكامل
```

## 3. بنك الأسئلة

### المنهج
- **بنك ضخم مُولَّد مسبقاً:** أسئلة بالذكاء الاصطناعي ومراجعة يدوية، مخزّنة كـ JSON ثابت
- **اختيار عشوائي:** كل جلسة تأخذ أسئلة مختلفة بتوزيع متوازن
- **لا تكرار** في الجلسة الواحدة
- **تحديث دوري** — يمكن إضافة أسئلة باستمرار

### الأنواع الـ6

| النوع | الوصف | المدة | مثال |
|---|---|---|---|
| **mcq** (اختيار من متعدد) | مواقف حياتية، ليست أسئلة مدرسية | 30 ثا | "زميلك يقول AI يفكر مثل الإنسان، ما موقفك؟" |
| **true_false** | عبارات تبدو بديهية لكنها ليست كذلك | 30 ثا | "AI يستطيع كتابة عقد قانوني يُعتمد مباشرة" |
| **fill_blank** | قائمة منسدلة داخل جملة | 25 ثا | "تقنية ___ تمكّن ChatGPT من توليد النصوص" |
| **matching** | ربط عناصر من عمودين | 45 ثا | "وصّل كل أداة بمجال تميّزها" |
| **sorting** | ترتيب خطوات أو أولويات | 45 ثا | "رتّب خطوات حل مشكلة بـ AI" |
| **self_assessment** | سلّم أو موقف، بلا إجابة صح/خطأ | بلا مؤقت فردي | "مديرك أعلن أداة جديدة، أول فكرة..." |

### مبادئ صياغة الأسئلة

**أسئلة المعرفة والمهارات:**
- مواقف حياتية واقعية، ليست امتحان مدرسي
- تسمح بإجابات "صحيحة جزئياً"

**أسئلة التقييم الذاتي (قاعدة ذهبية):**
- **غير مباشرة دائماً** — لا "هل أنت مرن؟" بل موقف يكشف مرونته
- **كل الخيارات تبدو عقلانية** — لا "يفضح نفسه"
- **لا توحي بالإجابة المطلوبة** — المقاوم للتغيير يختار بارتياح
- **تقيس السلوك الفعلي** — "ماذا تفعل فعلاً؟" لا "ماذا يجب أن تفعل؟"

**مبدأ التشويق:**
- كل سؤال يحقق واحداً على الأقل من:
  - **يُفاجئ** (إحصائيات، معلومات جديدة)
  - **يُثير تفكيراً شخصياً** (سيناريوهات تخيّلية)
  - **يُشعر بتحدٍ ممتع** (توصيل، ترتيب)
- **السؤال الذي لا يحقق أياً منها يُحذف**

## 4. نظام التوقيت

### المدة الإجمالية (يختارها المستخدم)

| الوضع | المدة | الأسئلة | مناسب لـ |
|---|---|---|---|
| سريع | 5 د | ~10 | فكرة عامة سريعة |
| مختصر | 10 د | ~18 | تقييم بوقت قصير |
| **معياري** | **15 د** | **~25** | التوازن (الافتراضي) |
| مفصّل | 20 د | ~32 | تقييم أعمق |
| شامل | 30 د | ~45 | أقصى دقة |

### مؤقت فردي لكل سؤال

| النوع | المدة |
|---|---|
| mcq, true_false | 30 ثا |
| fill_blank | 25 ثا |
| matching, sorting | 45 ثا |
| self_assessment | **بلا مؤقت فردي** |

### سلوك انتهاء الوقت
- إشارة بصرية + منع الإجابة + رسالة "انتهى الوقت"
- المستخدم يضغط "التالي" بنفسه (لا تلقائي)
- السؤال = 0 نقاط
- **السؤال الذي ذهب لا يعود** — لا "السابق"

### الحماية من الغش
- المدد قصيرة بما يكفي لمنع البحث (40-60 ثا حد أدنى للبحث)
- محاولة Refresh: تحذير `beforeunload` ثم إنهاء الاختبار
- **عرض سؤال واحد في كل شاشة**
- **النتائج بعد الانتهاء فقط**

## 5. نظام الأوزان والتقييم

### تصنيف الأسئلة حسب الغرض

| الفئة | الغرض | الوزن | مثال |
|---|---|---|---|
| **جوهرية (core)** | فهم حقيقي / مهارة فعلية | وزن كامل (3-4 نقاط) | "Prompt غامض — لماذا النتيجة سطحية؟" |
| **ثقافية (cultural)** | ممتعة، إحصائيات، لكن لا تعكس جاهزية فعلية | 1 نقطة | "كم عدد مستخدمي ChatGPT؟" |
| **تقييم ذاتي (self_assessment)** | المرونة عبر مواقف غير مباشرة | لا تدخل في النقاط — معامل ضرب | "مديرك يعلن أداة جديدة..." |

### نقاط الجوهرية

| النوع | النقاط | الحساب |
|---|---|---|
| mcq | 3 | مثالية=3، جزئية=1، خاطئة=0، "لا أعرف"=0.5 |
| true_false | 3 | صح=3، خطأ=0 |
| fill_blank | 3 | صح=3، خطأ=0 |
| matching | 3 | كل توصيلة نسبياً (3/4 = 75% × 3) |
| sorting | 4 | كل عنصرين متجاورين بالترتيب = نقطة |

### نقاط الثقافية

كلها 1 نقطة فقط (صح=1، خطأ=0).

### معامل المرونة (من التقييم الذاتي)

| المستوى | المعامل |
|---|---|
| مقاومة عالية للتغيير | 0.7 |
| مقاومة متوسطة | 0.85 |
| محايد | 1.0 |
| مرونة جيدة | 1.15 |
| مرونة استثنائية | 1.3 |

### المعادلة النهائية

```
الجاهزية = درجة المعرفة والمهارات (من 100) × معامل المرونة (0.7 — 1.3)
```

**أمثلة:**
- معرفة 80% × مرونة عالية (1.2) = **96** — رائد رقمي
- معرفة 80% × مقاومة (0.8) = **64** — واعٍ متردد
- معرفة 50% × مرونة استثنائية (1.3) = **65** — مبتدئ قابل للتطور

## 6. هيكل التقرير

### القسم 1 — الملخص التنفيذي
- درجة الجاهزية (gauge بصري كبير)
- التصنيف:
  - 90-100: **رائد رقمي**
  - 75-89: **متقدم**
  - 60-74: **واعٍ**
  - 40-59: **مبتدئ**
  - <40: **في خطر**
- جملة شخصية تلخّص أبرز نقطة قوة وضعف

### القسم 2 — تفصيل المحاور (Radar Chart)
4 محاور:
1. **المعرفة الأساسية** — هل تفهم AI؟
2. **الممارسة الفعلية** — هل تستخدم أدواته؟
3. **المرونة والاستعداد** — عقلية منفتحة؟
4. **الوعي التخصصي** — كيف يؤثر على مجالك؟

كل محور بلون: أخضر (قوي) / أصفر (متوسط) / أحمر (ضعيف).

### القسم 3 — كشف المعادلة بشفافية
- عرض المعادلة بصرياً (أعمدة + ضرب)
- جملة توضيحية: "درجتك في المعرفة 76. مرونتك (×1.08) رفعت جاهزيتك إلى 82."

### القسم 4 — التوصيات المخصصة
- ضعف معرفة → مصادر تعلم محددة
- ضعف ممارسة → تحدي عملي ("جرّب ChatGPT في مهمة هذا الأسبوع")
- ضعف مرونة → رسالة تحفيزية واقعية
- ضعف تخصصي → توجيه AI + تخصصه

### القسم 5 — المقارنة والمشاركة
- "أنت أفضل من X% في مجال [تخصصه]"
- زر مشاركة (يولّد صورة/رابط)

### القسم 6 — أعد الاختبار
- "الجاهزية ليست ثابتة — أعد بعد شهر"
- زر يبدأ اختباراً جديداً

### Schema للسؤال

#### الحقول المشتركة
```json
{
  "id": "gen-mcq-014",
  "type": "mcq",
  "purpose": "core",
  "axis": "knowledge",
  "time_seconds": 30,
  "points": 3,
  "text": { "ar": "...", "en": "..." },
  "hint_after": { "ar": "...", "en": "..." }
}
```

| الحقل | النوع | الوصف |
|---|---|---|
| `id` | string | `[قسم]-[نوع]-[رقم]` (مثل `gen-mcq-014`) |
| `type` | string | mcq / true_false / fill_blank / matching / sorting / self_assessment |
| `purpose` | string | core / cultural / self_assessment |
| `axis` | string | knowledge / practice / flexibility / specialty |
| `time_seconds` | number\|null | المدة (`null` للتقييم الذاتي) |
| `points` | number | 3-4 جوهرية، 1 ثقافية، 0 تقييم ذاتي |
| `text` | `{ar, en}` | نص السؤال |
| `hint_after` | `{ar, en}` | شرح يظهر في التقرير |

#### Schemas الخاصة بكل نوع

```json
// mcq
"options": [
  { "id": "a", "text": {ar, en}, "score": 0|0.5|1|3 }
]

// true_false
"correct_answer": true|false

// fill_blank
"text": "تقنية {{blank_1}} تمكّن ChatGPT...",
"blanks": [
  { "id": "blank_1", "correct": {ar, en}, "options": [{ar, en}...] }
]

// matching
"left":  [{ "id": "L1", "text": {ar, en} }, ...],
"right": [{ "id": "R1", "text": {ar, en} }, ...],
"correct_pairs": [{ "left": "L1", "right": "R1" }, ...]

// sorting
"items": [{ "id": "S1", "text": {ar, en} }, ...],
"correct_order": ["S1", "S2", "S3", "S4"]

// self_assessment
"options": [
  { "id": "a", "text": {ar, en}, "flexibility_score": 1-5 }
]
```

## 9. آلية التحميل

1. عند فتح الصفحة: `questions-index.json` فقط
2. عند بدء الاختبار: `general.json` يُحمَّل
3. بعد العامة (المرحلة 1.5): شاشة اختيار التخصص
4. عند الاختيار: ملفات التخصصات المختارة فقط
5. مسار التحميل: `../../assets/data/ai-readiness/{filename}.json`

### التوزيع
- **35% أسئلة عامة + 65% تخصصية**
- **عدة تخصصات:** توزيع متساوٍ (5+5، أو 4+3+3)
- داخل كل تخصص: اختيار عشوائي من بنكه

## 10. الإضافات اللاحقة (موجودة لكن لم تُذكر في الـ spec الأصلي)

### `recommendations.json`
توصيات لكل مستوى وكل محور (knowledge/practice/flexibility/specialty).
البنية: `{level}_{axis}: { icon, color, title, items: { ar: [...], en: [...] } }`.

### `tips.json`
نصائح قصيرة تظهر بين الأسئلة (إن أمكن) أو في صفحة الانتظار.

### `personal-summary.json`
جمل افتتاحية شخصية للتقرير، تستخدم `{{name}}` placeholder. مقسّمة حسب المستوى:
- at-risk
- beginner
- aware
- advanced
- pioneer

## 11. الإضافة (تخصص جديد، أسئلة، توصيات)

### إضافة تخصص جديد
1. أنشئ `src/assets/data/ai-readiness/{id}.json` بنفس بنية `general.json`
2. أضف entry في `questions-index.json` تحت `sections[]` (مع `id`, `name`, `category`, `file`, `code`)
3. التخصص يظهر تلقائياً في شاشة الاختيار

### إضافة أسئلة لقسم موجود
أضف objects في `questions[]` بنفس Schema. كل سؤال يحتاج: `id`, `type`, `purpose`, `axis`, `time_seconds`, `points`, `text`, `hint_after`.
