# ✍️ استراتيجية المحتوى | Content Strategy

> المدونة ليست ترفاً — هي الجسر بين البحث في Google وأدواتك. كل أداة تستحق محتوى يدعمها.

---

## 1. الفلسفة

- **الجمهور أولاً:** نكتب لإنسان يبحث عن إجابة، ليس لمحرك بحث
- **الدقة قبل الكمية:** مقال صحيح فقهياً/علمياً > 10 مقالات سطحية
- **العربية أصيلة:** ليست ترجمة. الإنجليزية أصيلة أيضاً
- **القيمة قبل الطول:** 800 كلمة مفيدة > 2,000 كلمة حشو
- **الربط بالأدوات:** كل مقال يدعم أداة (CTAs + related tool card)

## 2. نموذج Pillar / Sub-Articles

كل موضوع كبير له **مقال رئيسي (Pillar)** + **مقالات فرعية (Subs)**.

### مثال: زكاة المال

**Pillar:** `how-to-calculate-zakat.md` — دليل شامل لحساب الزكاة
**Subs:**
- `zakat-on-gold-jewelry.md` — زكاة الذهب
- `zakat-on-stocks.md` — زكاة الأسهم
- `zakat-on-cryptocurrency.md` — زكاة العملات الرقمية
- `zakat-on-real-estate.md` — زكاة العقارات
- `zakat-on-debts.md` — زكاة الديون
- `zakat-on-salary.md` — زكاة الراتب
- `zakat-on-savings-for-house.md` — زكاة المال المدخر
- `zakat-to-relatives.md` — هل تجوز الزكاة للأقارب؟
- `zakat-vs-zakat-alfitr.md` — الفرق بين زكاة المال وزكاة الفطر

### القواعد

- **Pillar** يحوي قسم "مواضيع ذات صلة" يربط بكل الـ Subs
- **كل Sub** يربط بالـ Pillar + 1-2 Subs ذات صلة (في وسط المقال، ليس فقط في النهاية)
- **روابط cross-topic** مرحّبة (مثلاً: مقال زكاة يربط بمقال ميراث حين يناسب)

## 4. CTA (Call to Action) Placement

كل مقال يجب أن يحوي **2 CTAs على الأقل** (الـ relatedTool card في النهاية يُحسب 3rd):

### CTA 1: في المقدمة (بعد الفقرة الأولى)
```html
<div class="blog-cta">
  <div class="blog-cta-icon">🕌</div>
  <div class="blog-cta-body">
    <p>هل تريد الحساب مباشرة؟ إذا كنت تعرف الأساسيات وتريد حساب زكاتك الآن:</p>
    <a href="/ar/tools/zakat-calculator.html">احسب زكاتك الآن ←</a>
  </div>
</div>
```

### CTA 2: في وسط المقال (بعد قسم تعريفي مهم)
نفس النمط بنص مختلف يناسب السياق.

### CTA 3 (تلقائي): related tool card في النهاية
يُحقن تلقائياً من `build.js` إذا frontmatter يحوي `relatedTool`.

## 5. Frontmatter (Required)

```yaml
---
title: "كيف تحسب زكاة المال؟ دليل شامل مع أمثلة عملية"
description: "كيف تحسب زكاة مالك بدقة؟ شروط الوجوب، النصاب، نسبة 2.5%، وأمثلة عملية على النقود والذهب والأسهم"
date: "2025-10-05"
topic: "zakat-calculator"
keywords: "حساب زكاة المال، كيف أحسب الزكاة، نصاب الزكاة، نسبة الزكاة، حاسبة زكاة"
relatedTool: "zakat-calculator"
---
```

| الحقل | إلزامي؟ | الملاحظات |
|---|---|---|
| `title` | ✅ | h1 + `<title>` (50-60 حرفاً) |
| `description` | ✅ | meta description (150-160 حرفاً) |
| `date` | ✅ | YYYY-MM-DD |
| `topic` | ✅ | tool ID من `tools.json` أو `"news"` |
| `keywords` | ✅ | متنوعة بين عربي وعامي وأسئلة |
| `relatedTool` | اختياري | لإظهار related tool card في النهاية |

```markdown
[تعريف موجز]
```

## 7. أنماط نصية موحّدة

### العناوين (h2, h3)

- **سؤالية حين يمكن:** "كيف تحسب زكاة الذهب؟" أفضل من "حساب زكاة الذهب"
- **قصيرة:** أقل من 60 حرفاً
- **بدون وسوم HTML معقدة**

### الفقرات

- **3-5 جمل لكل فقرة**
- **استخدم bold للمفاهيم المهمة:** **النصاب** هو الحد الأدنى...
- **استخدم *italics* للمصطلحات الفقهية أو التقنية**

### الجداول

استخدمها لـ:
- مقارنات (مذاهب، أنظمة تقدير)
- معادلات
- شروط

### القوائم

- **مرقمة** للخطوات
- **نقطية** للنقاط المتساوية الأهمية

## 8. الكلمات المفتاحية في المقال

- العنوان (h1) يحوي الكلمة المفتاحية الرئيسية
- أول 100 كلمة تحوي الكلمة المفتاحية
- 2-3 عناوين فرعية (h2) تحوي variations
- النص يستخدم الكلمات بطبيعية، **لا keyword stuffing**

## 9. الترجمة بين اللغتين

كل لغة **مستقلة**:
- المقالات في `src/blog/ar/` و `src/blog/en/` لا يجب أن تكون متطابقة 1:1
- الكلمات المفتاحية تختلف بين اللغتين
- الأمثلة قد تختلف (مثلاً: ريال سعودي للعربي، USD للإنجليزي)
- لكن **المعلومة الأساسية يجب أن تكون متسقة** (لا تتناقض)


## 11. الطول الموصى به

| نوع المقال | عدد الكلمات | الملاحظات |
|---|---|---|
| Pillar (دليل شامل) | 1,500-2,500 | يغطي الموضوع كاملاً |
| Sub (موضوع محدد) | 800-1,500 | عميق لكن مركّز |
| News/announcement | 300-600 | قصير ومباشر |

## 12. Checklist لمقال جديد

- [ ] frontmatter كامل (كل الحقول الإلزامية)
- [ ] description بين 150-160 حرفاً
- [ ] title بين 50-60 حرفاً
- [ ] CTA مرتين على الأقل
- [ ] روابط لمقالات أخرى ذات صلة (داخل النص)
- [ ] أمثلة عملية (أرقام، سيناريوهات)
- [ ] قسم FAQ (إن أمكن)
- [ ] اختبار البناء: `npm run build` ينتج المقال بدون أخطاء
- [ ] فحص الرابط النسبي: `/ar/...` و `/en/...` (build.js يحوّلها تلقائياً)
