5. ابني واختبر

## ما شروط وجوب الزكاة؟

قبل أن تحسب الزكاة، تأكد من تحقق هذه الشروط:

* **الإسلام:** الزكاة واجبة على المسلم فقط.
* **الملك التام:** أن يكون المال مملوكاً لك ملكاً كاملاً.
* **بلوغ النصاب:** أن يبلغ المال حداً أدنى معيناً.
* **حولان الحول:** أن يمر على المال سنة هجرية كاملة.

## الـ Frontmatter بالتفصيل

| الحقل | إلزامي؟ | الطول/الصيغة | مثال |
|---|---|---|---|
| `title` | ✅ | 50-60 حرفاً | `كيف تحسب زكاة المال؟ دليل شامل` |
| `description` | ✅ | 150-160 حرفاً | (انظر القالب) |
| `date` | ✅ | YYYY-MM-DD | `2026-05-08` |
| `topic` | ✅ | tool ID أو `"news"` | `zakat-calculator` |
| `keywords` | ✅ | متنوعة | (انظر أدناه) |
| `relatedTool` | اختياري | tool ID | `zakat-calculator` |

### `topic` — القيم المسموحة

- أي `id` من `tools.json`: `zakat-calculator`, `inheritance-calculator`, إلخ
- `"news"` للإعلانات وأخبار الموقع

### `keywords` — استراتيجية الكتابة

```
حساب زكاة المال، كيف أحسب الزكاة، نصاب الزكاة، زكاة المال، نسبة الزكاة، كم زكاة المال، طريقة حساب الزكاة، حاسبة زكاة، مقدار الزكاة
```

اشمل:
- ✅ الكلمة الرئيسية
- ✅ صيغ سؤالية ("كيف أحسب", "كم زكاة")
- ✅ صيغ بالعامي ("الزكاه" بدل "الزكاة")
- ✅ مرادفات ("نصاب" + "حد أدنى")
- ✅ النية ("حاسبة" تدل على نية البحث عن أداة)

## بنية المحتوى الموصى بها

### المقدمة (50-150 كلمة)
- اطرح المشكلة من زاوية المستخدم
- استخدم سؤالاً مباشراً
- لا تبدأ بـ "في هذا المقال سنشرح..."

### CTA 1 (بعد المقدمة)
زر للأداة المرتبطة لمن يريد القفز مباشرة.

### الأقسام الرئيسية (h2)
- 4-7 أقسام
- كل قسم 100-300 كلمة
- استخدم h3 للأقسام الفرعية

### CTA 2 (في وسط المقال)
بعد قسم تعريفي مهم، CTA ثاني بنص مختلف.

### أمثلة عملية
- أرقام واقعية
- سيناريوهات حقيقية (شخصيات بأسماء)
- جداول أحياناً

### FAQ (3-5 أسئلة)
أسئلة فعلية يبحث عنها الناس.

### مواضيع ذات صلة (للـ Pillar فقط)
روابط لكل الـ Subs.

### relatedTool Card (تلقائي)
لا تكتبه — `build.js` يحقنه.

## ثنائية اللغة — كل لغة مستقلة

- المقالات في `src/blog/ar/` و `src/blog/en/` **لا يجب أن تكون متطابقة 1:1**
- الكلمات المفتاحية تختلف بين اللغتين
- الأمثلة قد تختلف (ريال سعودي vs USD)
- لكن **المعلومة الأساسية متسقة**

```bash
# ليس إلزامياً وجود نسخة لكل لغة، لكنه مفضّل للمواضيع المهمة
src/blog/ar/how-to-calculate-zakat.md   # الأهم
src/blog/en/how-to-calculate-zakat.md   # الأقل أهمية إن كان الجمهور عربي
```

## Pillar vs Sub

### Pillar (دليل شامل)
- 1,500-2,500 كلمة
- يغطي الموضوع كله
- **يحوي قسم "مواضيع ذات صلة"** يربط بكل الـ Subs
- مثال: `how-to-calculate-zakat.md`

### Sub (موضوع محدد)
- 800-1,500 كلمة
- يعمّق نقطة واحدة
- **يربط بالـ Pillar** (في وسط النص، ليس في النهاية فقط)
- يربط بـ 1-2 Subs ذات صلة
- مثال: `zakat-on-gold-jewelry.md`

## Pre-publish Checklist

- [ ] frontmatter كامل
- [ ] description 150-160 حرفاً
- [ ] title 50-60 حرفاً
- [ ] CTA على الأقل مرتين
- [ ] روابط داخلية لمقالات أخرى (في وسط النص)
- [ ] أمثلة عملية بأرقام واقعية
- [ ] FAQ section (3-5 أسئلة)
- [ ] لو Pillar: قسم "مواضيع ذات صلة"
- [ ] لو Sub: روابط للـ Pillar
- [ ] الكلمة المفتاحية في h1، أول 100 كلمة، 2-3 h2
- [ ] لا keyword stuffing (احتشاد غير طبيعي)
- [ ] `npm run build` ينتج المقال بدون أخطاء
- [ ] افتح المقال في المتصفح وتحقق من العرض
