## 2. الأدوات المقترحة لتعبئة التصنيفات الفارغة

> ⚠️ كل ما يلي **مقترحات للنقاش**. سنختار منها بناء على الأولوية والقيمة للمستخدم العربي.

### 2.1 محوّلات (`converters`) — 5 مقترحات

| الأداة | الوصف | تعقيد | قيمة |
|---|---|---|---|
| محوّل الوحدات | length, weight, volume, temperature, area, speed | متوسط | عالية |
| محوّل العملات | تحويل بين عملات (مع API مجاني أو بيانات ثابتة محدّثة) | متوسط+ | عالية جداً |
| محوّل التواريخ | Hijri ↔ Gregorian (مع شهور متعددة وتقاويم بديلة) | متوسط | عالية للجمهور المسلم |
| محوّل المنطقة الزمنية | الوقت في مدن مختلفة، فرق التوقيت | بسيط | متوسطة |
| محوّل أحجام الملفات | KB/MB/GB/TB، base 2 vs base 10 | بسيط | متوسطة |

### 2.2 أدوات نصية (`text`) — 4 مقترحات

| الأداة | الوصف | تعقيد | قيمة |
|---|---|---|---|
| عداد كلمات/أحرف | للعربية والإنجليزية، مع إحصائيات (أحرف، كلمات، فقرات، وقت قراءة) | بسيط | عالية |
| محوّل حالة النص | uppercase/lowercase/title case/sentence case | بسيط | متوسطة |
| منسّق النص العربي | إزالة تشكيل، توحيد همزات، إزالة تطويل (ـــ) | متوسط | عالية للكتّاب |
| مولّد Lorem Ipsum | عربي + إنجليزي + خيار طول الفقرة | بسيط | متوسطة |

### 2.3 وقت وتاريخ (`datetime`) — 4 مقترحات

| الأداة | الوصف | تعقيد | قيمة |
|---|---|---|---|
| التقويم الهجري الكامل | شاشة شهر/سنة، تحويل، أعياد إسلامية | متوسط+ | عالية |
| حاسبة المواعيد | "كم يوماً حتى X؟" / "ما تاريخ بعد Y يوم؟" | بسيط | متوسطة |

| حساب أيام العمل | استبعاد الجمعة/السبت/العطل الرسمية | متوسط | متوسطة |

### 2.4 أدوات صور (`image`) — 3 مقترحات

| الأداة | الوصف | تعقيد | قيمة |

| مغيّر حجم الصور | تغيير الأبعاد بحفاظ على النسبة | بسيط | متوسطة |

### 2.5 أدوات مطورين (`developers`) — 5 مقترحات

## 6. غير مخطط الآن

> ✍️ **ملاحظة:** بعض هذه القرارات **قِيَمية ثابتة** والبعض الآخر **حالة حالية قد تتغيّر**. التمييز مهم.

### 🚫 لن نفعله (قِيَمي)

- ❌ **تتبّع متقدّم للمستخدم** (نكتفي بـ AdSense fundamentals، لا analytics مفصّلة)
- ❌ **اشتراكات تخفي ميزات أساسية** (إعلانات فقط)
- ❌ **"Coming soon" placeholders** — إما الأداة جاهزة، أو لا توجد
- ❌ **بيع/مشاركة بيانات** المستخدمين

### 📅 لا نفعله الآن (قد يتغيّر لأدوات محددة)

| لا الآن | قد نفعله لـ... |
|---|---|
| **قواعد بيانات** | أداة محددة تحتاج تخزيناً persistent (مثل تتبع GPA عبر فصول، حفظ نتائج ai-readiness) |
| **نظام تسجيل/حسابات** | أداة محددة تستفيد من حفظ بيانات المستخدم عبر الأجهزة |
| **Backend جزئي (serverless)** | أداة تتكامل مع API خارجي (مثل أسعار عملات حية) |
| **تطبيق Native (iOS/Android)** | غير مرجَّح — Web App يكفي. لكن لو الحاجة واضحة، غير ممنوع |
| **Native frameworks (React Native, Flutter)** | لو قرّرنا native app يوماً |
| **AI integration runtime** (LLM API) | حالات نادرة جداً تستفيد فعلياً (تكلفة + خصوصية يجعلانها صعبة) |

**القاعدة:** لو أضفنا أحد هذه، نضيفه **لأداة محددة معزولة** — لا نُحوّل الموقع كله إلى SaaS.
