## 🏛️ قرارات أساسية

### دعم 20 نظاماً تقديراً
- **القرار:** نُغطّي الدول العربية الرئيسية + الدول العالمية الأكثر طلباً
- **السبب:** الطلاب العرب يدرسون عالمياً، يحتاجون تحويلاً
- **القيد:** كل نظام يحتاج بحثاً وفحصاً

### السعودي 5.0 افتراضي
- **القرار:** أكثر استخداماً في الجمهور المستهدف
- **القابلية للتغيير:** localStorage يحفظ آخر اختيار

### النظام الألماني مقلوب
- **القرار:** 1.0 = أفضل، 5.0 = رسوب — يطابق النظام الفعلي
- **التحدي البرمجي:** يكسر افتراض "الأعلى أفضل" في كل مكان
- **التطبيق:** flag `inverted` في كل template، الكود يعكس الحسابات والألوان

### تخصيص شامل
- **القرار:** المستخدم يستطيع تعديل كل شيء (قيم، تقديرات، max)
- **السبب:** الجامعات تختلف داخل نفس الدولة أحياناً
- **التطبيق:** `customizations` في localStorage، `getActiveTemplate()` ترجع المعدّل أو الأصلي

### التحويل عبر النسبة المئوية كوسيط
- **القرار:** للتحويل بين نظامين، نمرّ بالنسبة المئوية
- **السبب:** كل نظام له mapping إلى/من النسبة، التحويل المباشر بين 20×19 = 380 mapping (غير عملي)
- **التطبيق:** `toPercent(val, fromId)` → `fromPercent(pct, toId)`

## 🏗️ قرارات معمارية

### `getActiveTemplate()` كنقطة وصول وحيدة
- كل الحسابات والـ UI تستخدمها — لا تقرأ `templates[id]` مباشرة
- استثناءات قليلة: `updateTemplateDescription()`, `updateDropdownLabel()` (للاسم الأصلي)

### what-if دائم (لا toggle)
- **القرار:** عمود what-if دائم الظهور
- **السبب:** أبسط منطقياً، أقل ضغطاً على المستخدم لاكتشاف ميزة

### Save/Load كامل الحالة
- يصدّر: template، customizations، سياسة الإعادة، المواد، الفصول، حالة المحوّل
- **السبب:** يستعيد كل شيء بالتفصيل، لا فقدان

---

## ⚠️ حالات حافّة

| الحالة | المعالجة |
|---|---|
| لا مواد | GPA = — |
| كريديتس = 0 | المادة لا تُحسب |
| إعادة بدون تقدير قديم | يُحسب الجديد فقط |
| النظام مقلوب | كل المقارنات معكوسة |
| GPA > max | تحذير |

## 🎓 دروس

- **20 نظاماً يبدو كثيراً** لكن كل نظام بسيط بمفرده — التعقيد في التداخل (التحويل)
- **`isInverted()` flag** يقتصر على template واحد، لكنه يؤثر على ~10 دوال
- **piecewise linear interpolation** كافٍ للتحويل (لا حاجة لمنحنيات معقدة)
