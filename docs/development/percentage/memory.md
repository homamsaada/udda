## 🏛️ قرارات

### نمط "math sentence" أفقي
- **القرار:** كل حاسبة في سطر واحد كجملة رياضية
- **السبب:** بسيط، مرئي، يفهمه أي مستخدم فوراً
- **البديل المرفوض:** نموذج عمودي بـ form fields — أكثر مللاً

### نتائج فورية (oninput)
- **القرار:** لا submit button
- **السبب:** للحاسبات البسيطة، الانتظار غير مبرَّر
- **التحدي:** التعامل مع inputs فارغة (نُظهر `—` بدلاً من 0)

### isPercent و signed كـ flags
- `isPercent = [2, 8, 11, 12, 13]` → النتيجة بـ `%`
- `signed = [3, 7, 11]` → قد تكون سالبة، تُلوَّن
