## 🏛️ قرارات معمارية

### File I/O بدل localStorage saved groups (2026-05-12 — v2.1)
- **القرار:** حذف نظام "المجموعات المحفوظة" (localStorage) واستبداله بنظام ملفات JSON.
  - تصدير/استيراد حالة الرحلة كاملة (`schema: v2`)
  - تصدير/استيراد قائمة buyers فقط (`schema: v2-group`)
- **السبب:** localStorage محصور في المتصفح الواحد، الملفات قابلة للمشاركة بين الأجهزة وبين الأشخاص، وتفتح الباب لتعديل يدوي إن لزم. أيضاً يفصل بين "هذه الرحلة" و"قائمة الناس" بشكل أوضح.
- **التطبيق:** `Blob + URL.createObjectURL + anchor.click()` للتصدير، `FileReader` + `try/catch` على JSON.parse للاستيراد. النمط مأخوذ من `family-tree.html` و `gpa-calculator.html`.
- **Migration:** في الـ init، `localStorage.removeItem('udda:abu-najeeb:groups')` لتنظيف الـ legacy تلقائياً.

### Treasurer toggle inline في لوحة تعديل الـ buyer (2026-05-12 — v2.1)
- **القرار:** حذف قسم "Settlement Settings" المنفصل (dropdown) ونقل اختيار الأمين إلى داخل لوحة تعديل الـ buyer (toggle button).
- **السبب:** القسم المنفصل كان يضيف ضوضاء بصرية. منطقياً، اختيار "هذا الشخص أمين الصندوق" يتعلق بالـ buyer ذاته، فالمكان الطبيعي للخيار هو في عرض/تعديل الـ buyer.
- **التطبيق:** زر toggle داخل `.an-edit-panel` يعكس الحالة (active إن كان هذا الـ buyer هو الأمين). الـ auto-suggest (أكبر دائن) يبقى فعّالاً عند `state.treasurer === null`.

### Excel export بنفس نمط loan-calculator (2026-05-12 — v2.1)
- **القرار:** تصدير `.xlsx` متعدد الأقسام: Title → Summary → Anonymous → Buyers → Expenses → View A → View B.
- **السبب:** Excel أكثر مرونة للمستخدمين الذين يريدون مشاركة النتائج كملف رسمي (محاسب، مدير رحلة).
- **التطبيق:** `ExcelJS.Workbook` مع RTL للعربية، indigo header `#6366F1`، alternating gray rows، numFmt `#,##0` للمبالغ، `+#,##0;-#,##0;0` للصافي مع لون أخضر/أحمر.
- **Lazy loading:** نفس النمط مثل html2canvas — `ensureExcelJS()` بـ Promise.

### Bulk + Buyers + إلغاء المرافقين (2026-05-12 — refactor كبير ثاني)
- **القرار:** نموذج جديد يقسم المشاركين إلى bulk anonymous (4 buckets: full/half/quarter للـ anonymous + buyers مسمَّون). إلغاء مفهوم "المرافقين" كلياً.
- **السبب:** النموذج السابق كان يفترض إدخال كل شخص بالاسم. في رحلات 20-30 شخص، هذا غير عملي. الواقع: "نحن 25، منهم 4 اشتروا أغراضاً" — لا داعي لتسمية الـ 21 الباقين.
- **القرارات الفرعية المُتَّفق عليها:**
  - الـ buyers **داخل** العدد الكلي (إضافة buyer تنقص bulk.full بـ 1)
  - **لا مفهوم مرافقين مطلقاً** — كل شخص في bucket واحد فقط (لو احتاج المستخدم نموذج "أب يدفع عن عائلته"، يضيف buyer واحد بـ shareFactor مُجمَّع، أو يستخدم أداة أخرى)
  - Greedy mode **محذوف نهائياً** — يفقد معناه مع anonymous bulk (تحويلات peer-to-peer بين أشخاص بلا أسماء؟)
  - عرض النتيجة في وجهَين: View A (inbound to treasurer = bulk + debtor buyers) + View B (outbound from treasurer = creditor buyers)
- **النطاق المُحدَّد بوضوح في الـ intro:** كل مشارك يدفع حصته **بنفسه** للأمين. ليست لحالات "أب يدفع عن عائلته" بالشكل المُتعقّب فردياً.

### Trip-only mode (2026-05-11 — refactor كبير أول، تم تطويره لاحقاً)
- **القرار:** حذف نمط Quick (التبويبات الأربعة) بالكامل. الأداة Trip-only.
- **السبب:** الأداة فلسفياً للرحلات الكبيرة (10+ أشخاص). "من دفع لمن" هو الناتج النهائي دائماً. خلط طُرق التقسيم مع المخرج كان معمارياً ملتبساً.
- **الحلّ:** المُدخَل = أشخاص + مصاريف (مع `paidBy` و `sharedWith`). المخرَج = تسوية. "التقسيم" يتحقّق عبر `sharedWith` (الجميع = متساوي، subset = استهلاكي).
- **تطوُّره في v2 (2026-05-12):** `sharedWith` حُذف (المشاركة الآن implicit = الجميع حسب shareFactor)، الـ people استُبدِلَت بـ bulk + buyers.

### نموذج أمين الصندوق (2026-05-11، عُزِّز في 2026-05-12)
- **القرار:** Treasurer هو الافتراضي. في v1 كان Greedy متاحاً كـ toggle، في v2 **حُذف Greedy نهائياً**.
- **السبب:** في المجموعات الكبيرة، Greedy يعطي كل شخص 2-3 تحويلات لأشخاص مختلفين = فوضى نفسية. نموذج "أمير الرحلة" المُتّبع واقعياً يجعل كل شخص يتعامل مع واحد فقط. مع bulk anonymous، Greedy يفقد معناه الرياضي أيضاً.
- **اختيار الأمين:** auto = أكبر دائن (متطوّع طبيعي)، يدوي عبر dropdown. **قيد v2:** الأمين يجب أن يكون buyer (مسمَّى)، لا أحد anonymous يصلح.

### Site-wide English numerals (2026-05-11)
- **القرار:** `App.formatNumber` يستخدم `en-US` دائماً (0,1,2,3,...) في AR و EN.
- **السبب:** الأرقام العربية-الهندية (٠،١،٢،٣) تربك المستخدمين العرب الذين تعوّدوا الأرقام الغربية في السياقات التقنية. وحدة العرض عبر اللغتَين.
- **الأثر:** كل الأدوات الـ12 (ليس abu-najeeb فقط).

### الأشخاص مشتركون عبر التبويبات (single source of truth) — تاريخي
- **القرار (الإصدار الأول):** `state.people` قائمة واحدة، شريط الأشخاص يظهر **خارج** `.calc-pane`
- **في الإصدار الحالي:** لم يعد هناك تبويبات أصلاً، الأشخاص هم single source طبيعياً.

### الأرقام صحيحة فقط (لا فواصل عشرية)
- **القرار:** `Math.round` بعد كل قسمة، لا أرقام عشرية في النتائج
- **السبب:** spec الأصلي طلب ذلك، وهو منطقي للسياق الاجتماعي (لا أحد يحوّل 23.47 ر.س)
- **التحدّي:** rounding errors تتراكم → آخر شخص دائن يحصل على `total - Σ(الآخرين)` لإغلاق التوازن

### المرافقون: محذوفون كلياً في v2 (سابقاً 3 presets في v1)
- **القرار في v1 (2026-05-11):** كل person له `companions` (عدد) + `companionShare` (full/half/quarter موحَّد لكل المرافقين). تطبيق مبسَّط، 3 presets فقط، نسب مخصّصة مؤجَّلة.
- **القرار في v2 (2026-05-12):** **إلغاء المفهوم كلياً.** كل شخص في الرحلة يُعَدّ مرة واحدة في bucket واحد (bulk.full/half/quarter أو buyer مفرد). لا يحمل أحد "مرافقين".
- **السبب:** المفهوم خلط بين "شخص يدفع عن عائلته" و"عائلة تشارك في رحلة". في v2 الافتراض الفلسفي: **كل مشارك يدفع حصته بنفسه للأمين**. لو احتاج المستخدم تتبّع "أب يدفع عن عائلته"، يضيف buyer واحد بـ shareFactor مُجمَّع، أو يحفظ الأمر خارج الأداة.
- **بديل v2.1:** نسب مخصّصة (custom %) لو طُلِب لاحقاً (مثلاً 30%، 40%، إلخ).

### العملة حقل اختياري نصّي، لا تدخل الحساب
- **القرار:** input صغير "العملة (اختياري)"، نصّ يُلصق بالنتيجة فقط
- **السبب:** spec يقول "بدون عملة محدّدة"، لكن المستخدمين عملياً يحتاجون مرجعاً بصرياً في الناتج
- **المثال:** قيمة `currency='ر.س'` تجعل النتيجة `350 ر.س` بدلاً من `350`

### Greedy لتسوية Tab 3 — تاريخي، محذوف في v2
- **القرار v1 (2026-05-11):** Greedy، ليس Linear Programming. sort by net، أكبر دائن يأخذ من أكبر مدين حتى أحدهما = 0، كرّر. مرجع: Splitwise وأخواتها.
- **القرار v2 (2026-05-12):** **حُذف نهائياً.** مع anonymous bulk، التحويلات الفردية بلا أسماء بلا معنى. نموذج الأمين فقط.

### sessionStorage + localStorage منفصلان
- **القرار:**
  - `sessionStorage["udda:abu-najeeb:session"]` — full state، auto-save شفّاف (schema=`v2` في v2)
  - `localStorage["udda:abu-najeeb:groups"]` — قائمة buyers المسمَّاة فقط (اسم + shareFactor)
- **السبب:** الجلسة شيء (يموت عند إغلاق تبويب)، المجموعات المُسمّاة شيء آخر (تبقى)
- **لا نخلط:** عند استرجاع مجموعة محفوظة، الـ buyers فقط يأتون، يُعاد ضبط `total = buyers.length` و `bulk = {0,0,0}` و `expenses = []` (كل رحلة مختلفة، الـ trip config لا يُحفَظ)
- **Migration:** v2 يكتشف schema القديم (`state.people` أو `state.settlementMode`) ويتجاهله. الـ saved groups القديمة (بـ `companions/companionShare`) تُحمَّل بإسقاط هذه الحقول وافتراض `shareFactor = 'full'`.

### html2canvas: lazy loading
- **القرار:** السكربت لا يُحمَّل عند فتح الصفحة، فقط عند الضغط الأول على "تصدير صورة"
- **السبب:** ~45KB، أغلب المستخدمين لن يحتاجوه، الـ TTI يبقى نظيفاً
- **التطبيق:** زر "تصدير صورة" يستدعي دالة async تُنشئ `<script src="...">` ثم تنتظر `load`

## ⚠️ حالات حافّة

| الحالة | المعالجة |
|---|---|
| أقل من شخصين | رسالة + تعطيل أزرار النتائج |
| مبلغ ≤ 0 أو غير رقمي | رفض + رسالة |
| Tab 4 — نسب ≠ 100% | إنذار بصري + ملخّص الفرق + السماح بالتنفيذ (مع تنبيه) |
| Tab 3 — كل المصاريف على شخص واحد | الباقون يدفعون له بالتساوي |
| Tab 3 — Σ(rounding errors) ≠ 0 | آخر دائن يحصل على الفرق |
| حذف شخص له مصاريف/طلبات | حوار تأكيد + cascade. لو الشخص = `paidBy` لمصروف → منع الحذف حتى يُغيَّر الـ payer |
| Tab 3 — مصروف بلا `paidBy` صالح | invalid، يُحذف من العرض |
| Clipboard API غير متاح (HTTP غير https) | fallback لـ `document.execCommand('copy')` |
| html2canvas يفشل (CORS مثلاً) | رسالة "تعذّر، حاول نسخ النص بدلاً" |

## ❌ ما تجنّبناه

- **مرافقون مخصّصون** بنسبة حرّة — UI معقّد، 3 presets كافية → v2
- **تصدير صورة بـ Backend** — مخالف لـ static-first، html2canvas client-side
- **حساب فوائد على ديون متأخرة** — الأداة اجتماعية، ليست بنكية
- **تصنيف فئات المصاريف** (طعام/مواصلات/...) — تعقيد بلا قيمة واضحة
- **مشاركة حالة عبر URL** — privacy concern (الأسماء في URL)، أُجِّل لـ v2 مع تشفير
- **disclaimer** — قُرِّر عدم وضعه (ليست شرعية/مالية بفوائد/طبية)
